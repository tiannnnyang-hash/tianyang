# 旅游全维度看板

一个纯前端、无后端的旅游销售数据看板。仓库现在只保留源码文本文件，避免二进制文件或脚本文件导致分支更新失败。

## 功能

- 账户池：先录账户、平台、账户总消耗、总加粉、总留资。
- 账户维度：自动汇总账户总消耗、总加粉、平均加粉成本、总留资。
- 销售维度：按销售实际承接留资拆分消费，统计销售总消费、订单、转化率、参与人数。
- 销售记录：选账户后自动带出账户数据，填写销售员、承接粉丝、承接留资、成交订单、收款金额后自动计算客单价、销售消费、利润和成单率。
- 员工明细：按销售员汇总所属账户、承接粉丝/留资、销售消费、收款、利润、成交订单和成单率。
- 智能排班建议：根据销售承接量、利润和转化率给出主力班、稳定班、培养班建议。
- 筛选导出：支持销售员、账户、日期范围筛选，并导出当前筛选后的 CSV。
- 数据保存在当前浏览器的 `localStorage` 中。

## 文件说明

现在仓库只需要这些文件：

```text
index.html
styles.css
app.js
README.md
```

## 使用方法

把整个文件夹下载到电脑后，双击 `index.html` 即可打开。

> 注意：`index.html`、`styles.css`、`app.js` 必须放在同一个文件夹里。

如果双击打开后浏览器限制了部分功能，可以在项目目录启动本地服务：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://localhost:4173/index.html
```
