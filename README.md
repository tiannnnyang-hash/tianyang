# 旅游员工每日业绩统计

一个无需后端的轻量级网页工具，适合旅行社或旅游销售团队记录员工每日数据。

## 功能

- 新增、编辑、删除每日员工记录
- 统计咨询量、加粉量、成交单数、成交率、成交金额
- 自动汇总当前筛选结果的团队总览
- 按员工姓名或日期搜索
- 数据保存在浏览器 `localStorage` 中
- 一键导出 CSV，方便用 Excel/WPS 继续分析

## 使用方法

直接用浏览器打开 `index.html`，或在项目目录启动一个本地服务：

```bash
python3 -m http.server 4173
```

然后访问 <http://localhost:4173>。
