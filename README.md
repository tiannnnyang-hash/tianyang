# 旅游全维度看板

一个纯前端、无后端的旅游销售数据看板。仓库现在只保留源码文本文件，避免二进制文件或脚本文件导致分支更新失败。

## 功能

- 记录每个销售员每天的咨询量、加粉量、成交单数、成交率、成交金额。
- 新增“广告账户”和“广告账户当天消费”，方便统计每个广告账户每天花了多少钱。
- 自动汇总总咨询、总加粉、总成交、成交率、成交金额、广告消费和利润。
- 按员工汇总业绩，按广告账户汇总消费。
- 保留截图里的筛选、导出 CSV、清空数据和排班建议。
- 数据保存在当前浏览器的 `localStorage` 中。

## 文件说明

现在仓库只需要这些文件：

```text
index.html
styles.css
app.js
README.md
```

## 使用方法

把整个文件夹下载到电脑后，双击 `index.html` 即可打开。

> 注意：`index.html`、`styles.css`、`app.js` 必须放在同一个文件夹里。

如果双击打开后浏览器限制了部分功能，可以在项目目录启动本地服务：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://localhost:4173/index.html
```
